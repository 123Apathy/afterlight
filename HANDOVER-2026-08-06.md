thing that reaches production is **`Deploy Everlit.cmd`** on this desktop.

whatever it finds locally and **never pushes**. GitHub's `main` contains zero

GitHub has never seen**. GitHub `main` last moved 2026-07-29.

## 3. The one thing that would have broken the deploy

`constants/demo.ts` statically requires `assets/demo/01.jpg … 08.jpg`. Those
files are **gitignored on purpose** — a real Margaret set would be family PII
and must never be committed. They are filled from the committed
`assets/demo-fallback/` set by `scripts/prepare-demo-photos.mjs`, which runs on
`postinstall`.

`Deploy Everlit.cmd` never ran `npm install`, so on a fresh pull the export
would have died with `Unable to resolve ../assets/demo/01.jpg`. It fails safe
("Deploy FAILED — production is unchanged"), but it would have blocked you.

Fixed in the deploy script. **Still run `npm install` after pulling**, both for
this and for the new `postinstall`/`sync-landing-tokens` scripts.
